# Domain docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the project root when it exists.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If either location does not exist yet, proceed without flagging its absence.

## Vocabulary

Use the domain terms defined by `CONTEXT.md` in issue titles, test names, interfaces, and implementation notes. Do not silently introduce synonyms for terms the glossary has defined.

If a proposed change contradicts an ADR, identify the conflict explicitly before implementation.
