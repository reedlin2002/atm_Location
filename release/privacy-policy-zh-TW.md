# 台灣 ATM Finder 隱私權政策

生效日期：由上架擁有者於公開發布時填寫。聯絡信箱：lin1022business@gmail.com。

台灣 ATM Finder 用來查詢公開 ATM 位置與已確認的服務資訊，不要求建立帳號，
不提供廣告，也不進行金融交易。離線 ATM 目錄、偏好銀行、篩選條件、最近搜尋
與收藏都只保存在使用者裝置的本機資料庫；本服務沒有帳號或跨裝置同步功能。

只有使用者主動按下「找我附近」時，App 才要求 Android 前景位置權限。當次
位置用來計算直線距離、排列附近 ATM，以及在使用者開啟地圖時設定搜尋區域；
App 不會儲存成位置歷史、不要求背景位置，也不會把位置加入資料回報或傳送到
本服務自有後端。使用者可以拒絕定位，改用完全離線的文字搜尋與清單流程。

首版 App 不整合 Firebase、Crashlytics、Analytics、廣告 SDK 或其他遠端診斷
服務；本服務不把搜尋、最近地點、收藏、ATM 選取或廣告識別碼傳送到自有後端。

地圖功能使用 Google Maps SDK for Android。依 Google 的 SDK 揭露文件，Maps
SDK 會自動蒐集裝置與請求中繼資料、SDK stack trace／crash metrics、IP 位址
及 Maps SDK 假名識別碼，並可能蒐集地圖平移、縮放等互動，以提供及改善 Google
服務。這些是 Maps SDK 的資料處理，不是本服務啟用 Crashlytics。使用地圖功能
時，資料另受 Google 隱私權政策及 Google Maps Platform 條款約束；使用者仍可
改用離線清單與文字搜尋。

使用者可透過設定頁刪除單筆或全部最近搜尋、取消收藏、清除篩選，或在二次確認
後重設所有本機資料。完整重設會移除偏好、最近搜尋、收藏與已安裝
ATM 目錄，並回到首次使用狀態。

ATM 資料回報會開啟使用者選擇的郵件 App，預填 ATM 穩定識別碼、公開場所資料、
資料版本與 App 版本；使用者可在寄送前查看、修改或取消。導航和分享會交由使用者
選擇的外部 App 處理，並受該服務自己的隱私權政策約束。若要查詢、更正或刪除
本機資料，或反映公開 ATM 資料問題，請使用設定頁重設功能或聯絡
lin1022business@gmail.com。
