# Financial features declaration 工作表

最終宣告由 Play Console 擁有者確認。聯絡：lin1022business@gmail.com。

台灣 ATM Finder 只顯示 ATM 的公開位置、銀行、場所、距離、來源、資料新鮮度，
以及有明確證據的存款、無障礙、外幣提款等服務狀態。App 不連線到銀行帳戶，
不讀取餘額或交易紀錄，不處理提款、存款、轉帳、付款、兌換、加密資產或任何
其他交易，也不保管金錢或付款工具。

建議 Financial features declaration：

- Banking／bank account management：否。
- Payments／money transfer／wallet：否。
- Loans／credit／buy now pay later：否。
- Investment／securities／crypto：否。
- Insurance：否。
- Credit score／financial advice：否。
- 其他金融產品或服務：否。

「同銀行優先」只是一個透明排序偏好。App 明確提醒使用者，是否同銀行不等於
免手續費，實際費率、跨行優惠、ATM 可用性、營業時間與服務狀態都必須向銀行
確認。地圖、導航、分享與資料回報也不構成銀行推薦、財務建議或交易保證。

上架擁有者應在每次送審前重新比對 Play Console 當下提供的金融功能分類與政策
文字，附上 App 詳情頁、手續費免責文字與此工作表作為證據。若日後產品加入任何
帳戶連結、交易、付款、貸款、投資或個人化財務建議，本工作表立即失效，必須先
進行新的產品、法務、資安與 Play 政策審查。
